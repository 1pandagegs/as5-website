Why Planning Determines Long-Term Value

Value isn't set at handover — it's set at the planning table. The decisions made before ground is broken are the ones that hold up decades later.

Most conversations about a development's value happen far too late — after the concept is fixed, after the budget is set, sometimes after ground has already broken. By then, the decisions that actually determine long-term value have already been made.

Value isn't primarily a function of finishes or amenities. It's a function of the choices made before a single drawing is finalized: how a site is read, how a program is sized against real demand, how flexibility is built in for uses that don't exist yet.

At AS5, planning is treated as its own discipline, not a formality before design begins. Every site is assessed on its own terms — orientation, access, soil conditions, neighboring context — before we let ourselves imagine what could be built there.

The temptation in development is always to move fast: lock a concept, secure financing, break ground. But the projects that hold their value ten and twenty years out are almost never the ones that moved fastest through this stage. They're the ones where someone insisted on getting the plan right first.

That's the case for treating planning as infrastructure, not preamble — because everything built on top of it, literally and figuratively, depends on getting it right.

"A building can be redesigned. A bad plan is much harder to undo."
